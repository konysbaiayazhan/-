# Жатақхана бөлмелерін брондау жүйесі

PHP және MySQL негізінде жасалатын веб-қосымша. Студенттер жатақханадағы бос бөлмелерді көріп, онлайн брондай алады, ал әкімші өтінімдерді растап немесе қабылдамай, бөлмелер мен жатақханаларды басқарады.

> **Жоба күйі:** 8-апта: жоспарлау кезеңі.

## Жобаның мақсаты

Жатақханаға орналасу процесін қағаз бен кезектен босатып, бөлмелерді брондауды онлайн, ашық әрі ыңғайлы етіп ұйымдастыру.

## Шешілетін мәселелер

- Бос бөлмелер туралы ақпаратты бір жерден көру мүмкіндігі.
- Қолмен жүргізілетін тізімдер мен қателердің азаюы.
- Брондау күйін студенттің өзі бақылай алуы.
- Әкімшіге өтінімдерді басқарудың ыңғайлы құралы.

## Пайдаланушы рөлдері

| Рөл | Мүмкіндіктері |
|-----|---------------|
| Қонақ | Басты бетті көру, тіркелу, кіру |
| Студент | Бөлмелерді іздеу, брондау, брондауларын көру және бас тарту, профильді өңдеу |
| Әкімші | Жатақхана мен бөлмелерді басқару, брондауларды растау немесе қабылдамау |

## Негізгі мүмкіндіктер

- Тіркелу, кіру және шығу (сессиялар, `password_hash`)
- Бөлмелерді іздеу, сүзу (жатақхана, қабат, баға, сыйымдылық), сұрыптау және пагинация
- Бөлмені күн аралығына брондау
- Менің брондауларым: күйін көру және бас тарту
- Әкімші панелі: жатақханалар, бөлмелер және брондаулар CRUD
- Деректерді валидациялау және қауіпсіздік шаралары

## Технологиялар

- **Backend:** PHP 8, PDO
- **Дерекқор:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Нұсқаларды басқару:** Git / GitHub
- **Хостинг:** InfinityFree (жоспарланған)

## Дерекқор құрылымы (ER-диаграмма)

![ER-диаграмма](docs/er-diagram.png)

| Кесте | Сипаттамасы |
|-------|-------------|
| `users` | Пайдаланушылар (студенттер мен әкімшілер) |
| `dormitories` | Жатақханалар |
| `rooms` | Жатақхана бөлмелері |
| `bookings` | Брондаулар |

**Байланыстар:** `dormitories` 1:N `rooms`; `users` 1:N `bookings`; `rooms` 1:N `bookings`.

SQL-скрипт: [database/schema.sql](database/schema.sql)
